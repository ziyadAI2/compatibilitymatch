# قاعدة بيانات العرض

الملف `compatibilitymatch_public.db` نسخة SQLite ثابتة للعرض والفحص في DBeaver. تتضمن بيانات الشركات والمصادر والسياق السوقي والتحليلات ودرجات التوافق والتوصيات.

أُزيلت منها مفاتيح الخدمة وحسابات المستخدمين وسجلات المراقبة قبل نشرها. لاستخدامها في DBeaver: أنشئ اتصال SQLite واختر هذا الملف.
